# Israt Jahan Tarifa - SQA Engineer Portfolio
Static site (HTML, CSS, vanilla JS). No build step.

## Replace placeholders in index.html
YOUR_GITHUB_URL, YOUR_LINKEDIN_URL, YOUR_CERTIFICATES_URL, GITHUB_PROJECT_URL (5 project cards)

## Deploy
GitHub > Repository > Settings > Pages > Deploy from branch > main / root

## Contact form
Static: opens the visitor's email app. Connect a service (e.g. Formspree) in script.js to send directly.
